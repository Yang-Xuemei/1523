# Todo-list 微信小程序需求

## 功能

- 任务创建与移除：文本输入框支持按下 Enter 键或点击按钮快速添加任务；每条任务均配有独立的删除按钮，点击即可实时从列表中移除
- 状态标记与反馈：每条任务左侧设有状态复选框，勾选后任务文本自动呈现删除线效果并标记为"已完成"，再次点击可取消标记恢复为"活跃"状态
- 多维度视图筛选：列表底部提供"全部"、"进行中（活跃）"、"已完成"三个切换按钮，点击后根据任务状态无刷新筛选显示对应内容
- 动态待办计数器：实时统计并显示当前处于"全部"、"进行中（活跃）"、"已完成"三个状态的任务总数，该数字随任务的添加、删除或状态切换自动更新
- 数据持久化：任务列表在重新打开后，内容与状态均能完整恢复
